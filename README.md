## About

**Builder Gym** is a responsive, full-featured gym web app built for users to manage their fitness journey anytime, anywhere. Users can register, update their profile, follow professional workout and diet plans, track progress, and manage subscriptions. Admins can manage users, plans, and content efficiently through a secure dashboard.

---

## Features

- **User Authentication:** Secure login/signup using Firebase Authentication.  
- **User Profiles:** Personalized profiles to track goals, workouts, and diet.  
- **Workout Plans:** Professionally designed routines for weight loss, muscle gain, or general fitness.  
- **Diet Charts:** Daily and weekly diet plans aligned with workout routines.  
- **Progress Tracking:** Visual and data-based tracking of physical progress.  
- **Subscription Management:** Manage membership plans easily.  
- **Admin Dashboard:** Control users, plans, and website content.  
- **Image Uploads:** Upload profile pictures and transformation images.  
- **Responsive Design:** Optimized for mobile, tablet, and desktop.  
- **Dark Mode (optional):** Comfortable browsing experience.  
- **Instant Feedback:** Real-time notifications for actions like updates, submissions, or errors.  
- **Educational Content (optional):** Space for fitness tips, videos, and guides.  

---

## Technologies Used

- **Frontend:** React, Vite, Tailwind CSS, Ant Design  
- **Backend / Database:** Firebase Authentication, Firebase Firestore, Firebase Storage  
- **Other Features:** Responsive UI, real-time notifications, image uploads

## Usage

1. Visit the live demo (link).  
2. Register or log in to your profile.  
3. Browse workouts and diet charts.  
4. Track your progress visually and via data.  
5. Admins can log in to manage users, plans, and content.
